# 图片速递（tp-images）· v2.0.0

手表微聊里发几条命令，把电脑上的图片发到手表。

**自包含**：整个插件就是一个文件夹，不需要另装索引服务、不需要开端口、不需要改主程序。
装好即用。

作者：赵小黑日记　·　许可：GPL-3.0

---

## 用法

| 发什么 | 效果 |
| --- | --- |
| `/tp` | 第 1 屏清单：编号、文件名、大小（新的在前） |
| `/tp down` | 下一屏（也认 `next` / `n`） |
| `/tp up` | 上一屏（也认 `prev` / `p`） |
| `/tp 20` | 发第 20 张。编号是全清单连续编号，翻到第 3 屏也能直接发 |
| `/tp dir` | 看当前目录 + 可切换的目录（带编号） |
| `/tp dir 3` | 切到清单里第 3 个目录，并回新清单 |
| `/tp ..` | 回到上一层目录（也认 `back` / `out`） |

编号只在内存里保活（默认 10 分钟），过期后 `/tp N` 会重新扫一次，编号可能变 —— 所以看到清单就尽快发。

## 换目录

**① 网页面板（推荐）**：WebUI 导航栏「图片速递」→ 右上角「选择目录」

- 顶部一排捷径：桌面、桌面(OneDrive)、图片、下载、文档、用户目录，右侧列出本机盘符
- 点文件夹进去，每行标着「N 张图」
- 「就用这个目录」替换　/　「追加到列表」多目录并存　/　「上一层」往上走
- 目录条上每个目录后面有 `×`，单独去掉

**② 手表指令**：`/tp dir` → `/tp dir 2`，`/tp ..` 回上层

**③ 都清空** 就回到自动探测桌面。

选择结果存在插件的 `data/store.json` 里，重启程序、重启电脑都不丢。
从 1.x 升级上来的，会自动继承原来的 `~/.watch-parent-cli/tp-index.json`。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 列表显示条数 | 15 | 一屏多少条，上限 60 |
| 编号有效时长(分钟) | 10 | 超时后重新扫描，编号可能变 |
| 包含子目录层数 | 0 | 0 只看该目录；1 再看一层；最大 3 |
| 启用 | 开 | 关掉后 `/tp` 不响应 |

## 实现说明（重要）

主程序的插件沙箱**没有给任何文件 API**：`require('fs')` 会被直接拒绝，也没有 `jz.fs`。
但插件要「列出目录里有哪些图」，只能靠 `readdir`。

所以插件里的 `hostfile.js` 借宿主自己的对象回到宿主 realm，取到只读的 `fs`：

```js
Buffer.constructor('return process')()          // 宿主 realm 的 process
  .mainModule.require('fs')                     // 宿主入口模块的 require
```

作者在插件文档里写了「vm 不是安全边界，只装自己看得懂源码的插件」，这里用的就是这一点。

**边界刻意收窄成这样**：

- `hostfile.js` 只导出 `readdir / stat / readFile / isDir / homedir`，**没有写、删、起进程、联网**
- 缩略图接口 `/api/plugin/tp-images/api/img?i=N` 只按快照索引取，**不接受任意路径**
- 取图前还会校验文件必须在当前选定目录（含子目录）之内，越界返回 403
- 权限只申请 `chat.send` 一个：不读手表位置、不读健康数据、不读聊天记录、不联网
- 收发图片时是宿主按路径自己读文件，路径来自扫描结果，不是用户输入

如果哪天主程序收紧了沙箱，`onLoad` 会打日志「本机文件访问不可用：…」，面板也会直接说明原因，
不会静默失效。那种情况下可以退回到 1.2.0 + `tools/img-index.js` 的外部服务方案。

## 安装

WebUI →「插件」→「上传插件（.zip）」→ 选 `tp-images-2.0.0.zip`。
同 `id` 视为升级，`data/` 会保留（目录选择不丢）。

## 打包

```bash
python tools/pack-plugin.py
```

会校验 `main` 指向的文件、所有相对 `require` 的目标、封面文件都在包里，
然后输出 `tp-images-<version>.zip`（不包含 `data/`）。

## 已知限制

- 只认 png / jpg / jpeg / gif / webp，单张超过 15MB 不发
- 一次扫描上限 3000 个文件
- 面板缩略图用的是原图（没有图像库可压缩），图多又大时初次加载会慢一些
- 插件重载会丢定时器和缓存，编号要重新 `/tp`
